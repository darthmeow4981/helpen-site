# helpen-site

The public face of **Helpen** — a private journal of small kindnesses.

This repository exists to serve a handful of files over HTTPS:

| file | used by |
|---|---|
| `logo.png` | the sign-in email, which shows the app's icon above the code |
| `icon-1024.png` | the full-resolution source |
| `privacy.html` | the privacy policy both app stores require at a public URL |
| `index.html` | a single page, so anyone who looks up the domain finds something |

Nothing secret lives here. The app itself is in a separate private repository.
